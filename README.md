# Bài 1: Kiểm Tra Cài Đặt Docker Engine và Chạy Container Hello-World

## 🎯 1. Mục Tiêu
- Thực hành chạy các lệnh kiểm tra phiên bản Docker CLI và khởi chạy container đầu tiên trên máy cá nhân.
- Đảm bảo kết nối tới Docker Daemon ổn định và hoạt động chính xác.

---

## 🛠️ 2. Các Lệnh Thực Hiện
1. **Kiểm tra phiên bản Docker CLI & Server**:
   ```bash
   docker version
   ```
2. **Kiểm tra thông tin chi tiết hệ thống Docker Engine**:
   ```bash
   docker info
   ```
3. **Khởi chạy container kiểm tra**:
   ```bash
   docker run hello-world
   ```
